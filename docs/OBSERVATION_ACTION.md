# 관측·행동·보상 계약

세 구현 — 엔진 상태 → 관측(TypeScript), 화면 인식 → 관측(Python), 관측 → 정책(TypeScript/Python/PyTorch) — 이 같은 스키마를 씁니다. 두 인코더(`src/observation/obs.ts`, `vision/observation/encode.py`)는 엔진 고정값에서 1e-6 이내로 일치하고, 내보낸 정책의 TypeScript 추론은 PyTorch와 1e-4 이내로 일치합니다 (pytest).

## obs-v1 (84 float32, 자기 중심 좌표)

원점 = 자기 머리 중심, +x = 진행 방향, +y = 화면 시계 방향 90°. 모든 특징은 **화면에서 볼 수 있는 양**으로만 정의했습니다 (카메라는 머리 주변 반경 480 u 원을 항상 보여 줍니다).

| 인덱스 | 특징 | 정규화 | 화면에서 얻는 방법 |
|---|---|---|---|
| 0 | log 길이 | `clip(ln(L/240)/ln 50, −1, 1)` | HUD 길이 게이지 |
| 1 | 몸통 반경 | `r/30` | r(L) |
| 2 | 부스트 가능 | `L > 160` | HUD 부스트 점 |
| 3, 4 | 직전 회전, 직전 부스트 | 그대로 | 정책 자신의 기억 |
| 5 | 부스트 연료 | `clip((L−160)/200, 0, 1)` | HUD 게이지 |
| 6–37 | 광선 16개 × (몸통 표면 거리, 벽 거리) | `/400`, 범위 밖 = 1 | 장애물 마스크 광선 진행, 경기장 사각형 교차 |
| 38–53 | 먹이 섹터 8개 × (값 합, 최근접 거리) | `ln(1+합)/ln 201`, 거리 `/400` | 먹이 원 검출, 반경 → 값 |
| 54–81 | 가까운 상대 머리 4개 × (있음, x/450, y/450, cos, sin 상대 방향, 속도 단계, 반경비) | 속도 단계 `(v−150)/150`, 반경비 `log2(r_o/r)/2` | 눈 쌍 검출, 추적기 속도 |
| 82 | 관측 신뢰도 | 엔진 = 1 | 격자 신뢰도 × 방향 출처 × HUD 가용성 |
| 83 | 프레임 나이 (s) | 엔진 = 0 | 캡처 후 경과 시간 |

누락값은 "없음"으로 표현합니다: 광선 거리 1, 먹이 합 0·거리 1, 상대 슬롯 전부 0(있음 = 0). 엔진 정보를 화면 기반 정책에 몰래 전달하는 특징은 없습니다: 화면 기반 실행에서 모든 값은 `Detections`와 러너 자신의 이전 행동으로만 계산됩니다.

**알려진 관측 차이(정의상 화면에서 볼 수 없는 것).** 몸통 아래에 깔린 먹이는 그려지지 않으므로 화면 기반 먹이 합이 조금 작습니다. 렌더링 외곽선 때문에 몸통 표면이 약 0.07·r 두껍게 보입니다.

## act-v1 (18개 이산 행동)

`index = 회전단계·2 + 부스트`, 회전 단계 = {−1, −0.75, −0.5, −0.25, 0, 0.25, 0.5, 0.75, 1} × ω_max (+ = 시계 방향). 부스트를 쓸 수 없으면(L ≤ 160) 홀수 행동이 마스킹되며, 마스킹된 행동이 들어오면 같은 회전·부스트 없음으로 실행합니다. 행동은 결정 주기(3틱) 동안 유지됩니다.

**화면 입력으로의 변환(Vision Bridge).** 게임의 공식 마우스 입력은 "포인터 방향으로 최대 ω_max로 회전"입니다. 회전 단계 u를 θ_target = θ̂ + u·ω_max·0.1 s 방향(머리에서 160 px)에 포인터를 두는 것으로 구현하고, 부스트는 Space 키를 누르고 뗍니다. 결정이 늦으면 목표 방향에 도달한 뒤 회전을 멈추므로 act-v1과 완전히 같지는 않습니다 — 이 차이도 Sim-to-Visual 실험에 포함됩니다.

## reward-v1 (학습 환경, `rl/bridge/envs.ts`)

```
r = 0.01·ΔL + 0.5·처치 + (사망 ? −1 : 0.002)
```

ΔL = (먹은 양 − 부스트 손실), 결정 1회마다. 에피소드는 학습자 사망(종료) 또는 1200 결정 = 120초(절단)에서 끝납니다. 상대 지렁이는 부활합니다. Python 참조 엔진도 같은 보상을 계산해 골든 궤적과 1e-9 이내로 일치합니다.
