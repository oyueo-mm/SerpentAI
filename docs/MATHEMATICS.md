# 수학적 기반

## 1. 원호 적분 (unicycle 모델)

진행 방향 θ, 속도 v, 각속도 ω(하위 스텝 동안 일정), 시간 h에 대해

```
θ' = θ + ω h
x' = x + (v/ω) (sin θ' − sin θ)
y' = y − (v/ω) (cos θ' − cos θ)          (|ω h| < 1e-9 이면 중간각으로 직선 근사)
```

이 해는 미분방정식 ẋ = v cos θ, ẏ = v sin θ, θ̇ = ω의 **정확해**이므로, ω가 일정하면 h를 어떻게 나누어도 같은 점에 도달합니다. 그래서 틱 30 Hz/60 Hz 결과가 1e-8 u 이내로 같고, 일정 회전 시 머리는 반지름 v/ω의 원 위에 1e-6 u 이내로 머뭅니다 (테스트로 확인).

## 2. 몸통 경로

몸통은 꼭짓점 p₀(꼬리) … p_n과 머리 h로 이루어진 폴리라인입니다. 확정 선분 길이의 합 `chainLen`을 증분으로 유지하며, 전체 길이 = chainLen + |h − p_n|.

꼬리 절단: 초과량 e = 전체 − L 에 대해, 첫 선분 길이 s₀ ≤ e 이면 p₀를 버리고 반복, 아니면 p₀ ← p₀ + (p₁ − p₀)·e/s₀. 꼭짓점이 원 위에 있을 때 꼬리 보간점은 현(chord) 위에 있으므로 원에서 최대 sagitta `c²/(8R)` (c ≤ 11 u, R = 47 u → 0.32 u)만큼 안쪽에 놓입니다.

## 3. 충돌 기하

**점–선분 거리.** t = clamp(((P − A)·(B − A)) / |B − A|², 0, 1), d² = |A + t(B − A) − P|².

**머리–몸통.** 머리 원(중심 h_i, 반경 r_i)과 캡슐(선분 AB, 반경 r_j)이 겹치는 조건: d(h_i, AB) < r_i + r_j. 관통 깊이 = r_i + r_j − d.

**머리–머리 (연속).** 두 머리가 하위 스텝 동안 선형 이동한다고 보면 상대 위치 p(t) = p₀ + t·v (t ∈ [0, 1]). 최근접 시각 t* = clamp(−p₀·v / |v|², 0, 1), 거리 |p(t*)|.

**관통 불가능성.** 하위 스텝 이동 ≤ 5 u, 접촉 대역 폭 2(r_i + r_j) ≥ 2·(7.8 + 7.8) = 31 u > 2·5 u이므로, 몸통 선을 가로지르는 머리는 반드시 어떤 하위 스텝 끝에서 대역 안에 있습니다. 테스트는 2400 u/s(틱당 80 u)에서 하위 스텝을 끄면 관통이 발생함을 보여 이 논증이 실제로 필요한 조건임을 확인합니다.

**광선–캡슐.** 원점 O, 단위 방향 D. 원점이 캡슐 안이면 0. 아니면 양 끝 원과의 교차(이차방정식)와, 선분에 평행한 두 직선(법선 n, 거리 ±r)과의 교차 중 선분 투영 구간 [0, |AB|] 안의 것의 최솟값입니다.

## 4. 공간 해시

96 u 균일 격자에 각 몸통 선분을 (반경만큼 부풀린) 경계 상자가 덮는 칸마다 등록합니다. 하위 스텝마다 다시 만들고(20마리 × L=1000, 3,340 선분 기준 0.14 ms), 질의는 스탬프 배열로 중복 방문을 막습니다. 결과가 질의 순서에 의존하지 않도록 모든 판정은 최솟값/최댓값과 id 동률 규칙으로만 결합합니다.

## 5. 관측과 좌표계

자기 머리를 원점으로, +x = 진행 방향, +y = 진행 방향에서 화면 시계 방향 90°. 월드 벡터 d의 자기 중심 좌표는 (d·f, d·r), f = (cos θ, sin θ), r = (−sin θ, cos θ). 장면 전체를 회전시켜도 관측(벽 제외)이 같음을 테스트로 확인합니다.

## 6. 화면 좌표 복원 (Vision)

카메라는 자기 머리를 화면 중앙에 두고 회전하지 않으며, 배율 z(px/u)는 `min(W, H) / (2·R_view(L))`, R_view ∈ [480, 600] u 입니다. 따라서

```
월드 변위 (u) = 화면 변위 (px) / z
```

이고, z는 바닥 격자(100 u 간격)의 화면 주기 P로 z = P/100 입니다. 주기는 열/행별 밝기 프로파일에서 이동평균을 뺀 신호의 자기상관 최댓값을 포물선 보간한 값(2배 조화 성분으로 보정)입니다. 탐색 범위는 위 카메라 규칙이 화면 크기로부터 허용하는 [0.9·m/1200, 1.1·m/960] (m = 짧은 변)으로 제한해 조화 주기 오인을 막습니다.

**시각 주행거리(odometry).** 카메라가 Δc(u) 이동하면 격자선은 −Δc·z px 이동합니다. 격자 위상 φ(복소 상관의 각도)를 프레임마다 재면 Δc = −Δφ/z (mod 100 u)이고, 이 모호성은 자기 명령으로 예측한 이동량 v·Δt에 가장 가까운 해를 골라 풉니다. 상대 머리의 위치는 이 주행 좌표계에서 칼만 필터(등속 모델)로 추적하여 속도를 얻습니다.

**먹이 값.** 먹이 값 v의 반경 r = 2 + 1.2√v 이므로 v = ((r − 2)/1.2)². 채도 임계값이 원의 안티앨리어싱 가장자리를 잘라 반경이 작게 측정되는 편향은 학습 세트에서 GT와 짝지어 측정한 중앙값 오프셋(px)으로 보정합니다 ([`vision/calibration/fit.py`](../vision/calibration/fit.py)).

## 7. 통계

- 평균의 95% 신뢰구간: t-분포 (`mean ± t_{0.975, n−1} · s/√n`).
- 비율(승률·사망률): Wilson score 구간.
- 짝지은 비교(Sim-to-Visual): 같은 시드끼리의 차이에 대한 t-구간.
