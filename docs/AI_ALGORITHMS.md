# 휴리스틱과 MPC

모든 내장 정책은 같은 인터페이스(`Policy.decide(ctx) → {action: act-v1, debug}`)로 결정 주기(10 Hz)마다 act-v1 행동 하나를 고르며, 같은 Match·토너먼트·평가 도구를 씁니다. 그래서 전문가의 행동을 그대로 모방학습 레이블로 쓸 수 있습니다. 휴리스틱과 MPC는 화면에 보이는 범위(머리에서 480 u 이내)의 엔진 상태만 사용합니다.

| 정책 | 핵심 아이디어 | UI에 그리는 것 (모두 실제 계산값) |
|---|---|---|
| Random | 무작위 회전 단계를 3–15 결정 동안 유지, 8% 확률로 부스트 | – |
| Greedy | 값/(거리 + 회전 비용)이 가장 큰 먹이로 향함. **벽만 피하고 몸통은 무시**(탐욕 전략의 한계 비교용) | 목표 먹이 |
| Survival | 16개 센서 광선만 사용하는 반응형. 앞쪽에 최소 회전 반경 2.2배 + 여유가 있으면 먹이가 가장 많은 방향(그 방향도 비어 있을 때만), 아니면 회전량 벌점을 뺀 가장 트인 광선으로. 광선 사이를 빠져나가는 얇은 몸통을 고려해 이웃 광선의 1.6배로 상한. 뒤에서 머리가 다가오면 부스트 도주 | 광선별 위험도, 목표 방향 |
| Aggressive | 자기보다 크지 않은 상대 머리를 골라 등속 직선 예측으로 **머리 앞 (3r + 25) u** 지점을 요격점으로 계산(고정점 반복 4회). 가까우면 부스트. 0.8초 원호 예측에서 충돌이 보이면 가장 오래 버티는 회전으로 회피. 상대가 없으면 사망 먹이 우선 수집 | 요격점(×), 목표 |
| Potential Field | 먹이 인력(값/d²), 몸통 척력(1/간격²), 벽 척력의 합력 방향으로 조향. 대칭 장애물 사이 국소 최솟값에 갇히는 문제를 그대로 둠 | 합력 방향 |
| Hybrid | 안전 계층: 9개 회전 단계 × (부스트 유무)를 1초 동안 pm-v1로 예측해 충돌 없는 행동만 남김 → 목표: 작은 상대 요격 > 좋은 먹이(사망 먹이 2배) > 중앙. 안전한 행동 중 끝 방향이 목표에 가장 가까운 것을 선택, 안전한 행동이 없으면 충돌까지 시간이 가장 긴 것 | 목표·요격점 |
| MPC | 아래 참조 | 모든 후보 궤적, 충돌 지점, 비용표 |

## 예측 모델 pm-v1 ([`src/ai/local.ts`](../src/ai/local.ts))

- 자기 머리: 엔진과 **같은 원호 적분**과 같은 부스트 비용. 그래서 예측 궤적은 실제 실행 궤적과 1e-6 u 이내로 일치합니다(테스트).
- 다른 몸통: 현재 위치에 고정.
- 다른 머리: 현재 속도로 직진하며, 지나간 자리를 몸통 캡슐로 남깁니다.
- 각 예측 시점의 여유 = 보이는 몸통 표면·예측 머리 캡슐·벽까지의 최소 거리(80 u 상한). 0 이하이면 그 시각을 충돌로 기록.

## MPC ([`src/ai/mpc.ts`](../src/ai/mpc.ts))

**후보.** 첫 구간에 act-v1 행동 하나(부스트 불가 시 부스트 행동은 마스킹 → 9개), 깊이 2이면 나머지 구간에 회전 단계 {−1, −0.5, 0, 0.5, 1} 중 하나. 기본: 지평 1.5초, 스텝 1/15초, 첫 구간 = 지평의 1/3 → 18 × 5 = 90개 궤적. 각 첫 행동의 점수는 가장 좋은 연속 행동의 점수입니다.

**목적함수.** 각 항목을 따로 계산하고 UI에 따로 보여줍니다.

```
total = 1·먹이 + 1·말단 가치 − 1000·충돌 − 4·안전 여유 − 0.5·부스트 비용
  먹이      = 궤적이 입으로 쓸고 지나가는 서로 다른 먹이의 값 합 (= 예상 성장)
  말단 가치 = 끝점 160 u 이내 먹이의 거리 가중 합 − 벽 150 u 이내 벌점 (충돌 궤적은 0)
  충돌      = 1 + (지평 − 충돌 시각)/지평  (일찍 부딪힐수록 큼; 충돌 없으면 0)
  안전 여유 = Σ max(0, 15 − 여유)/15 · Δt
  부스트    = 예상 길이 손실 (u)
```

충돌 가중치(1000)는 가능한 최대 먹이 이득보다 두 자릿수 이상 커서, 충돌이 예측된 궤적은 먹이가 아무리 많아도 선택되지 않습니다(테스트로 가중치 비율 확인). 첫 행동만 실행하고 다음 결정에서 다시 계획합니다(receding horizon).

**설명 가능성.** UI의 후보 경로·충돌 지점·비용표는 MPC가 실제로 반환한 `MpcCandidate` 배열을 그대로 그립니다. 같은 상태에서 다시 계획하면 같은 비용이 나오고, 실행한 행동이 최고 점수 후보와 같음을 테스트로 확인합니다. MPC 경량판(`mpc-lite`: 깊이 1, 지평 1초)은 학습 환경의 상대로 씁니다.

**한계(사실대로).** pm-v1은 다른 지렁이가 회전하거나 부스트하는 것을 예측하지 않습니다. 정면 충돌 규칙(긴 쪽 생존)을 공격적으로 활용하지도 않습니다. 계산 비용은 [`BENCHMARK.md`](BENCHMARK.md)에 측정값이 있습니다.
