# 모방학습: Behavior Cloning과 DAgger

실행: `python -m rl.imitate all --expert mpc --steps 200000 --dagger-steps 60000 --rounds 4 --epochs 10 --run il-v1` (Intel Core Ultra 7 256V, CPU만, 1,194초). 원본 기록은 `rl/runs/il-v1/` (git 제외), 요약은 [`public/data/rl/il-v1.json`](../public/data/rl/il-v1.json).

## 전문가와 데이터

- **전문가 = MPC** (지평 1.5초, 깊이 2). 같은 평가 조건에서 Hybrid보다 강하다는 토너먼트 결과에 따라 선택했습니다.
- **수집**: 시나리오 C-moving 25% / D-mixed 45% / E-attack 30%, 6개 브리지 × 8 환경. 전문가 행동을 실행하되 10% 확률로 무작위 유효 행동을 실행합니다(DART 방식 잡음) — 레이블은 항상 전문가 행동이며 실제 실행 행동은 따로 기록합니다(9.6% 상태에서 다름). 잡음 덕분에 전문가 혼자서는 가지 않는 복구 상황이 데이터에 들어갑니다.
- **기록 필드** (`rl/imitate.py:Dataset`): 관측(obs-v1), 전문가 레이블, 실제 실행 행동, 행동 마스크, 에피소드 ID, 에피소드 시드, 결정 틱, 보상, 종료 여부, 출처(0 = 전문가, k = DAgger 라운드), 메타데이터(전문가 이름, ε, β, 규칙·관측·행동·보상 버전).
- **분할**: 에피소드 단위 90/10 (같은 에피소드의 상태가 학습·검증에 동시에 들어가지 않음 — 테스트로 확인).

**데이터 구성 (d0: 200,016 상태, 305 에피소드)** — 평범한 먹이 수집 상태로만 채워지지 않았는지 확인하기 위해 상태를 자동 분류했습니다.

| 상태 유형 | 정의 (obs-v1) | 비율 |
|---|---|---|
| 전방 충돌 위험 | 전방 3광선 중 최소(몸통·벽) < 120 u | 4.2% |
| 몸통 근접 | 어떤 광선이든 몸통 < 60 u | 2.4% |
| 벽 근처 | 벽 광선 < 120 u | 7.2% |
| 포위 | 몸통 광선 8개 이상이 200 u 이내 | 0.7% |
| 급회전 | 전문가 |회전| ≥ 0.75 | 29.4% |
| 부스트 | 전문가 부스트 | 3.0% |
| 먹이 밀집 | 섹터 먹이 합 상위 약 10% | 9.5% |
| 상대 근접 | 가장 가까운 머리 < 180 u | 9.4% |

위험 상태가 드물기 때문에 학습 손실에서 가중치를 높였습니다: `w = 1 + 2·전방위험 + 몸통근접 + 벽근처 + 포위 + 상대근접` (평균 1로 정규화).

## Behavior Cloning

- 네트워크: PPO 액터와 **같은 구조**(SB3 MaskablePPO `MlpPolicy`, 84→256→256→18, tanh). BC 결과를 그대로 PPO의 초기값으로 쓸 수 있습니다.
- 관측 정규화: 전문가 데이터의 평균·분산(이후 모든 PPO 변형에도 같은 값으로 고정).
- 손실: 마스크된 로짓의 가중 교차 엔트로피, Adam 1e-3, 10 에포크, 배치 1024.
- 가치 함수 예열: 데이터의 몬테카를로 할인 리턴(γ = 0.99, 끝나지 않은 에피소드의 마지막 200 스텝 제외)으로 크리틱을 회귀 → PPO가 무작위 크리틱으로 시작해 BC 정책을 망가뜨리는 문제를 줄임.

## DAgger

```
라운드 k = 1…4:
  현재 정책(확률적 샘플링)이 행동, 확률 β_k = 0.5^k로 전문가 행동을 대신 실행
  방문한 모든 상태에 전문가(MPC) 레이블 → 6만 상태 추가 (누적)
  누적 데이터로 이전 가중치에서 이어서 학습 (5 에포크)
  독립 평가 시드에서 실제 게임 성능 측정
```

## 결과

평가: 시드 910000–910059(학습 시드와 분리, 라운드 선택에 사용 → 검증 세트 역할), 120초 상한, Node에서 내보낸 JSON 모델을 TypeScript 추론으로 실행. 괄호는 95% CI.

|---|---|---|---|---|---|---|---|

### 해석

- **행동 일치율이 낮아도 게임 성능은 다른 문제입니다.** MPC는 정확한 기하로 18×5개 궤적을 비교하므로 비슷한 점수의 행동이 많고, obs-v1의 16개 광선으로는 그 차이를 다 볼 수 없습니다. 그래서 정확 일치는 36% 수준에 머뭅니다.
- **BC는 전문가 성능의 약 절반**(생존 56.7 s vs 107.0 s)이고 사망률이 85%입니다 — 전문가가 가지 않는 상태로 벗어나면 회복하지 못하는 전형적인 공변량 이동(covariate shift)입니다.
- **DAgger는 도움이 됐지만 단조롭지 않았습니다.** r2에서 생존이 83.2 s로 BC 대비 +26.5 s (CI가 겹치지 않음)였으나, r3·r4는 64–68 s로 떨어졌습니다. 이 실험만으로 원인을 단정할 수 없습니다(라운드당 평가 60 에피소드, 학습 시드 1개). 가능한 요인: β가 작아질수록 정책 자신의 실패 상태 비중이 커져 전문가 레이블이 "이미 늦은 상황"의 행동으로 채워지는 점, 이어서 학습하며 생기는 과적합. **DAgger를 추가하면 반드시 개선된다고 주장하지 않습니다.**
- PPO-DAgger의 초기값은 검증 성능이 가장 좋은 r2를 썼습니다. 이 선택에 쓴 시드는 최종 평가(920000번대)에 쓰지 않습니다.
