# 테스트

| 명령 | 범위 |
|---|---|
| `npm test` | Vitest — 엔진 물리, 관측·행동 계약, 휴리스틱·MPC, Match, 악용 탐색, 페이싱 |
| `npm run build:node && python -m pytest rl/tests` | 브리지 계약, Gymnasium/SB3 검사, 결정론, Python 참조 엔진 동치성, Supervisor, BC/DAgger/PPO, 추론 동치성 |

| `npm run build && npm run test:e2e` | Playwright (데스크톱 Chrome + Pixel 7 에뮬레이션) |

CI([`.github/workflows/deploy.yml`](../.github/workflows/deploy.yml))는 위 전부를 실행한 뒤 GitHub Pages에 배포합니다. 대규모 학습(BC·DAgger·PPO·CNN)은 CI에서 돌리지 않고, 작은 스모크 학습만 테스트합니다.

## 게임 물리 (`src/sim/world.test.ts`)

직선 이동 거리 · 틱당 각속도 제한 · 일정 곡률 원 궤적(머리와 모든 확정 꼭짓점이 반지름 v/ω 원 위, 꼬리 보간점은 sagitta 이내) · 급회전+부스트 반복 시 몸통 연속성(선분 ≤ 11 u, 목 < 6 u) · 몸통 호 길이 = L · 틱 30/60 Hz 결과 일치(머리 1e-8 u, 몸통 형태 0.15 u) · 먹이 흡수와 성장 · 하위 스텝 사이 먹이 건너뛰기 없음 · 성장 시 꼬리 정지 · 두 머리가 노리는 먹이의 결정론적 배정 · 부스트 속도·비용·드롭 양 · 최소 길이에서 부스트 불가 · 몸통 충돌과 처치 기록 · 자기 몸통 무시 · 정면 충돌(같은 길이 둘 다 사망, 다르면 짧은 쪽) · 벽 · **관통 없음(12 위상 × 4 각도)** 과 **하위 스텝을 끄면 관통이 생김(2400 u/s)** · 사망 먹이 총량 · 같은 시드 = 같은 상태 · 저장→복원→계속이 비트 단위로 동일 · 다른 규칙 버전 거부 · 무작위 플레이 퍼징 3 시드 × 900 틱: **틱마다 정확한 질량 보존 법칙**(먹이 중복 섭취·유령 먹이를 잡아냄), 경기장 이탈 없음, 몸통 ≤ L, L ≥ 최소 길이.

## 휴리스틱·MPC·Match (`src/ai/ai.test.ts`)

## 렌더링 경로와 카메라 (`src/render/render.test.ts`)

실제 경기 240틱(급회전·부스트·성장·사망·부활 포함)의 프레임에서: 프레임 몸통이 끊김 없이 이어지고(선분 ≤ 11 u) 길이가 물리 몸통 길이 L 이하 · 두 틱 사이 보간(α = 0…1, 5,000건 이상)이 항상 하나의 연속 경로이고 길이가 두 틱 사이에 있으며 머리가 A에서 B로 단조 전진 · 렌더링 전용 곡선이 물리 경로에서 1 u 이내, 길이 98% 이상 유지 · 고배속(3틱 이상 차이)·부활은 보간하지 않음 · 카메라: 추적 모드 = 게임 카메라, 이동 시 자유 카메라가 보던 위치에서 시작, 커서 아래 점을 고정한 확대와 범위 제한, 다른 지렁이 선택·새 프레임에도 자유 카메라 유지, F로 추적 복귀 · 카메라 조작 전후 AI 관측 동일, AI 시야 오버레이 = 이번 틱의 엔진 센서 값.
